# Project Knowledge: Glucolog
* **Tech Stack:** Python, Django, Postgres
* **Goal:** A modern, user-friendly web application for convenient diabetes management (glucose and insulin tracking) as well as rough meal tracking.

## 1. Coding Style & Preferences
* Use Django best practices
* Write expandable, clean code, supported with sufficient comments
* Write clean, single-purpose functions.

## 2. Workflow & Constraints
* Create separate git branches when needed before starting to work on a new feature
